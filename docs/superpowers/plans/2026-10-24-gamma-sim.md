# gamma の偽ファームと rviz 可視化 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 実機なしで、rabbits_interface → robot_bridge → （pty）→ 偽ファーム → `joint_states` → rviz の経路を通し、gamma モデルの全関節が reference どおりに動くことを確認できるようにする。

**Architecture:** rabbits_sim の `gamma_fake_node` が pty の片側を開き、rabcl の共通プロトコルでファームを演じる（`FakeFirmware` がプロトコル、`GammaModel` が rabcl の制御部品で関節角を計算）。robot_bridge は実機と同じ設定で pty のもう片側を `device` に取る。rabbits_description に gamma の URDF（寸法は仮）、rabbits_bringup に横断 launch を置く。

**Tech Stack:** ROS 2 Jazzy、C++17（rclcpp、gtest）、rabcl（protocol / controller）、xacro、robot_state_publisher、rviz2。launch のみ Python。開発・テストは Docker（`rabbits/ros2-jazzy-dev`）で `colcon build` / `colcon test`。

**Spec:** `docs/superpowers/specs/2026-10-24-gamma-sim-design.md`（rabbits_sim）。ファームの振る舞いは gamma_turret_fw `docs/superpowers/specs/2026-10-23-gamma-control-design.md` と `src/control.cpp`（作業ツリー）が正。

## Review Focus

- bridge が pty をまだ開いていない / 閉じた直後に偽ファームが `Write` しても落ちない・止まらない（EAGAIN / EIO）。→ Task 3 `WriteWithoutReaderDoesNotBlock`。

  class RobotModel {  // 設計書 4.1 のとおり（純粋仮想）

### Task 5: rabbits_sim `GammaModel`

**Files:**
- Create: `include/rabbits_sim/gamma_model.hpp`, `src/gamma_model.cpp`, `test/test_gamma_model.cpp`
- Modify: `CMakeLists.txt`

**Interfaces:**
- Consumes: rabcl `BodyPosture`（`Solve(height, roll, pitch, yaw_offset, out[4])`）、`LegDamper`（`Update(target, angle, vel, dt)` → `MitCommand.pos`、`Reset`）、`OmniDrive(wheel_d, body_d)::CalcVel(vx, vy, wz, fr, fl, br, bl, offset_rot)`、`BodyAttitude::UpdateFromChassisRate(wz, dt)` / `Get()`、`Gimbal::Solve(desired, body)`、`CommandWatchdog(timeout)::Feed / Expired`、`Utils::WrapPi`。
- Produces:
  ```cpp
  namespace rabbits_sim {
  struct GammaConfig {
    float leg_angle_min, leg_angle_max, leg_tilt_gain; float leg_azimuth[4]; float leg_ramp_rate;
    double wheel_d, body_d; float wheel_sign;
    float chassis_vel_max, chassis_rot_max, spin_speed;
    float watchdog_s; bool follow_neck_pitch_roll;
  };
  class GammaModel : public RobotModel {
  public:
    explicit GammaModel(const GammaConfig &);
    // RobotModel の実装。joint_count 11、firmware_id "gamma-sm"
    float joint_angle(uint8_t id) const;   // テスト・ログ用
    bool command_lost() const;
  };
  }
  ```
- 関節の更新（`Update(now_s, dt)`。dt は 0〜0.05 にクランプ）:
  - lost = `watchdog.Expired(now_s)`（`OnCommandReceived` が `Feed`）。
  - 車輪: lost なら vx = vy = wz = 0。それ以外は `CHASSIS_VEL` をクランプし、`chassis == 1` なら `wz += spin_speed`。`OmniDrive::CalcVel(vx, vy, wz, …, yaw_angle)` の出力 × `wheel_sign` を角速度として積分し、`WrapPi`。`JointState.velocity` に角速度。
  - 脚: `BODY_POSE` を一度でも受けていれば `BodyPosture::Solve(height, roll, pitch, yaw_angle)` の値、まだなら `LegDamper::ramped_target()` を目標にして `LegDamper::Update(target, angle, 0, dt).pos` を関節角にする（lost でも同じ。最後の BODY_POSE へ進み切る）。初期角 `leg_angle_min`（コンストラクタで `Reset(leg_angle_min)`）。
  - 首 Yaw: `BodyAttitude::UpdateFromChassisRate(wz_total, dt)`（wz_total は上の車輪と同じ値。lost なら 0）。`JOINT_CMD` id 0 を受けていれば `Gimbal::Solve({yaw_cmd, 0, 0}, body).yaw` を関節角に、受けていなければ 0。
  - 首 Pitch / Roll: `follow_neck_pitch_roll` が true なら `JOINT_CMD` id 1 / 2 の position、false なら 0。
  - `error_flags` = bit4（常時）| bit5（lost）。
  - `JOINT_CMD` の id が 0〜2 以外、`MODE` の id が 4 以上は無視。
